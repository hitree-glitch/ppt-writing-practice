# Codex Chat Archive

This folder is generated by `tools/export_codex_chat_archive.py`.

The repository is configured to run that exporter from the Git pre-commit hook, so new commits can automatically refresh and stage this archive.

It exports only:

- user messages
- assistant messages

It intentionally skips raw internal log databases and developer/system prompt records.

Common secret-like strings such as API keys, tokens, and passwords are masked before the archive files are written.
