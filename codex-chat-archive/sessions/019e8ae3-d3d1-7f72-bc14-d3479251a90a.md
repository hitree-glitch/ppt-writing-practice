# 월별 실현손익 Google Sheets 자동 정리 계획

## Summary
- 키움증권·삼성증권에서 내려받은 CSV/엑셀 파일을 입력하면, 계좌별·월별 실현손익을 Google Sheets 리포트로 자동 생성한다.
- 대상은 국내+해외 주식이며, 집계 기준은 수수료·세금 반영 후 `순손익`이다.
- 해외주식 원화 환산은 증권사 원본 파일에 포함된 원화 손익 값을 우선 사용한다.
- 아직 샘플 파일이 없으므로 1차 버전은 범용 입력 템플릿과 매핑 구조로 만들고, 실제 파일 확보 후 컬럼명을 맞춰 보정한다.

## Key Changes
- 입력 구조:
  - `Broker`: 키움증권 / 삼성증권
  - `Account`: 계좌명 또는 마스킹 계좌번호
  - `TradeDate` 또는 `SellDate`: 실현손익 발생일
  - `Market`: 국내 / 해외
  - `Currency`: KRW / USD 등
  - `Symbol`, `Name`
  - `RealizedPnlKrw`: 원화 기준 순 실현손익
  - `FeesTaxesKrw`: 있으면 보조 지표로 보관
- Google Sheets 구성:
  - `Dashboard`: 전체 월별 순손익, 증권사별 합계, 계좌별 합계, 국내/해외 구분 요약
  - `Monthly`: `YYYY-MM` 기준 월별·증권사별·계좌별 피벗형 요약
  - `Raw`: 원본 입력을 정규화한 상세 내역
  - `Mapping`: 증권사별 파일 컬럼명과 표준 컬럼의 매핑표
  - `Checks`: 누락 날짜, 누락 손익, 미분류 증권사/계좌, 원화 손익 누락 검사용
- 자동화 방식:
  - 사용자는 증권사별 다운로드 파일을 지정 폴더에 넣는다.
  - 스크립트가 파일을 읽어 표준 컬럼으로 변환한다.
  - 변환 결과를 `.xlsx`로 만든 뒤 Google Sheets로 가져가거나, Google Sheets 연동이 가능하면 native Google Sheets로 업로드한다.
  - 계좌번호는 기본적으로 마스킹 처리하고, 리포트에는 사용자가 지정한 계좌 별칭을 표시한다.

- 국내+해외 데이터가 섞여 있어도 월별 합계가 `Dashboard`와 `Monthly`에서 일치하는지 검산한다.

- 월 경계일, 손실 월, 거래가 없는 월, 여러 계좌가 같은 종목을 거래한 경우를 테스트한다.

# 무인 월별 실현손익 Google Sheets 자동화 계획

## Summary
- 내 PC에서 실행되는 자동 수집기를 만든다.
- 키움증권은 공식 REST API를 우선 사용한다. API 키 발급 전에는 신청 절차와 설정 안내를 포함한다.
- 삼성증권은 공식 개인용 계좌 API가 확인되지 않으므로, “완전 무인” 조건에서는 1차 자동 수집 대상에서 제외한다.
- 결과는 Google Sheets에 월별·계좌별 실현손익 리포트로 갱신한다.

## Key Changes
- 수집 방식:
  - 키움: REST API OAuth 토큰 발급 후 계좌/실현손익성 조회 API를 호출한다.
  - 삼성: 공개 공식 API가 확인될 때까지 자동 수집 제외. 별도 원본 입력 없이 리포트에는 `삼성증권: 미연동` 상태를 표시한다.
  - Google Sheets: 로컬 수집기가 OAuth 인증 후 정규화 데이터를 업로드하거나 갱신한다.
- 리포트 구성:
  - `Dashboard`: 전체 월별 순손익, 키움 계좌별 합계, 국내/해외 구분 요약
  - `Monthly`: `YYYY-MM` 기준 월별·계좌별 피벗 요약
  - `Raw`: API에서 받은 표준화 상세 내역
  - `Accounts`: 계좌 별칭, 증권사, 연동 상태
  - `Checks`: 누락 손익, 누락 날짜, 해외 원화 손익 없음, API 오류 기록
- 보안/설정:
  - 키움 앱키·시크릿키와 Google OAuth 토큰은 내 PC의 로컬 설정 파일 또는 OS 보안 저장소에 보관한다.
  - 계좌번호는 리포트에 전체 노출하지 않고 별칭 또는 마스킹 값만 사용한다.
  - 매일/매월 자동 실행은 Windows 작업 스케줄러로 등록할 수 있게 설계한다.

## Test Plan
- 키움 API 키가 없는 상태에서 설정 누락 안내가 뜨고 Google Sheets가 잘못 갱신되지 않는지 확인한다.
- 키움 API 키가 있는 상태에서 계좌 목록, 기간별 실현손익, 국내/해외 구분이 `Raw`에 적재되는지 확인한다.
- 월별 합계가 `Dashboard`, `Monthly`, `Raw` 합산값과 일치하는지 검산한다.
- API 오류, 토큰 만료, 네트워크 실패 시 `Checks`에 기록하고 기존 정상 데이터는 덮어쓰지 않는지 확인한다.
- 삼성증권은 `미연동`으로 표시되고 전체 합계에서 잘못 포함되지 않는지 확인한다.

## Assumptions
- 사용자는 키움 REST API 사용 신청과 앱키/시크릿키 발급을 진행할 수 있다.
- 삼성증권은 완전 무인 수집을 위해 비공식 화면 자동화나 인증서 로그인 자동화를 사용하지 않는다.
- 해외주식 원화 손익은 API 또는 원본 응답에 원화 기준 값이 있을 때만 원화 합계에 반영한다.
- 현재 확인한 근거: [키움 REST API 가이드](https://openapi.kiwoom.com/guide/apiguide), [삼성 POP HTS Web 안내](https://english.samsungpop.com/eng/other/hts.do).
</proposed_plan>
