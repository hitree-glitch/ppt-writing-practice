`autoresearch`는 이걸 더 체계적으로 반복합니다:

```text
목표 정하기 → 시도 1 → 검증 → 별로면 버림
→ 시도 2 → 검증 → 나아지면 유지
→ 시도 3 → 검증 → 최종 정리
```

여기서 `Iterations: 3`은 “3번까지만 반복해라”라는 뜻이에요.  
너무 크게 잡으면 시간이 오래 걸리고 파일을 많이 만질 수 있어서 처음엔 3~5 정도가 안전합니다.

가장 쉬운 사용법은 이거예요:

```text
$autoresearch plan
이 문제를 어떻게 풀지 먼저 계획만 세워줘
```

실제로 고치게 하려면:

```text
$autoresearch fix
테스트 실패를 하나씩 고쳐줘
Iterations: 3
```

버그 원인을 찾게 하려면:

```text
$autoresearch debug
이 오류의 원인을 가설 세워서 확인해줘
Iterations: 5
```

즉, 외워야 할 건 거의 이것뿐이에요:

- `plan`: 먼저 계획만
- `fix`: 오류 고치기
- `debug`: 원인 찾기
- `improve`: 더 좋게 개선하기
- `security`: 보안 점검하기

실전에서는 그냥 이렇게 말해도 됩니다:

```text
이거 autoresearch로 먼저 계획만 세워줘
```

또는:

```text
이 버그 autoresearch로 3번만 시도해서 고쳐줘
```

한마디로, `autoresearch`는 **어려운 문제를 여러 번 실험하면서 풀게 하는 자동 반복 모드**라고 보면 됩니다.
