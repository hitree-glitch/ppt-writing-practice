## 폰트 대체 가능성

- 확인된 사용 폰트는 `Malgun Gothic`, `Calibri`, `Calibri Light`입니다.
- Windows PowerPoint 환경에서는 `Malgun Gothic`이 보통 기본 제공되므로 대체 가능성이 낮습니다.
- macOS 또는 한글 폰트가 제한된 환경에서는 `Malgun Gothic`이 다른 한글 폰트로 대체될 수 있습니다.
- 실제 제출 대상 PC의 설치 폰트와 PowerPoint 렌더링은 현재 도구만으로 확인 불가입니다.

## 확인 불가 항목

- 실제 Microsoft PowerPoint 데스크톱 앱에서 열었을 때의 최종 줄바꿈과 폰트 대체 상태는 확인 불가입니다.
- 수신자 PC에서의 폰트 설치 여부는 확인 불가입니다.
- PowerPoint UI에서 모든 객체가 개별 선택 가능한지 직접 클릭 검수는 확인 불가입니다. 다만 제작 방식은 텍스트와 기본 도형 중심입니다.
