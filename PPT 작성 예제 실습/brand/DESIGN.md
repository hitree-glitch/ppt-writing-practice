# AI 자동화 컨설팅 제안서 디자인 가이드

이 문서는 AI 자동화 컨설팅 제안서 PPT를 만들 때 참고할 디자인 초안입니다. 특정 브랜드의 공식 디자인 시스템이 아니며, 따뜻한 그린 카페 분위기에서 영감을 받은 제안서용 스타일 기준입니다.

## 1. 전체 분위기

제안서는 신뢰감, 편안함, 실행 가능성을 함께 보여줘야 합니다. 너무 차갑고 기술적인 화면보다, 차분한 크림 배경과 깊은 그린 색상을 사용해 안정적인 느낌을 만듭니다.

AI 자동화는 어렵게 보일 수 있으므로, 디자인은 복잡하지 않아야 합니다. 글은 짧게, 메시지는 크게, 흐름은 한눈에 보이게 구성합니다.

## 2. 핵심 디자인 방향

- 따뜻한 크림색 배경을 기본으로 사용합니다.
- 깊은 그린 색상으로 신뢰감과 전문성을 줍니다.
- 밝은 그린은 버튼, 강조 숫자, 핵심 키워드에만 사용합니다.
- 금색 계열은 성과, 프리미엄, 중요한 결과를 보여줄 때만 조금 사용합니다.
- 큰 장식보다 여백, 정렬, 간단한 도식으로 고급스러운 느낌을 만듭니다.

## 3. 색상 팔레트

| 역할 | 색상 | 사용 예시 |
|---|---:|---|
| 기본 배경 | `#F2F0EB` | 표지, 목차, 쉬어가는 슬라이드 |
| 보조 배경 | `#EDEBE9` | 구역 나누기, 흐름도 배경 |
| 카드 배경 | `#FFFFFF` | 문제, 해결책, 사례 카드 |
| 메인 그린 | `#006241` | 제목, 핵심 메시지 |
| 밝은 그린 | `#00754A` | 버튼, 강조 라벨, 진행 표시 |
| 딥 그린 | `#1E3932` | 강한 메시지 슬라이드, 마무리 슬라이드 |
| 소프트 그린 | `#D4E9E2` | 표 안의 긍정 표시, 약한 강조 배경 |
| 골드 포인트 | `#CBA258` | 성과 수치, 프리미엄 제안, 핵심 결과 |
| 본문 글자 | `#1F2933` | 일반 본문 |
| 보조 글자 | `#52606D` | 설명, 캡션, 작은 안내 |
| 주의 색상 | `#F59E0B` | 위험, 확인 필요, 의사결정 포인트 |

## 4. 색상 사용 규칙

- 한 슬라이드에서 진한 그린을 너무 많이 쓰지 않습니다.
- 밝은 그린은 클릭, 실행, 다음 단계처럼 행동을 유도하는 요소에 사용합니다.
- 골드는 많이 쓰면 가벼워 보일 수 있으므로, 중요한 성과나 핵심 수치에만 사용합니다.
- 본문은 순수 검정보다 부드러운 짙은 회색을 사용해 눈의 피로를 줄입니다.
- 배경은 흰색만 쓰기보다 크림색과 흰색을 번갈아 사용해 부드러운 리듬을 만듭니다.

## 5. 글꼴 방향

제안서는 한국어 가독성이 중요합니다. 아래 글꼴 중 사용 가능한 것을 선택합니다.

- 추천: Pretendard
- 대안: Noto Sans KR
- 기본 대안: 맑은 고딕

## 6. 글자 크기 기준

| 역할 | 권장 크기 | 굵기 | 설명 |
|---|---:|---:|---|
| 표지 제목 | 36-44pt | 굵게 | 제안서의 첫인상을 만듭니다. |
| 장표 제목 | 24-30pt | 굵게 | 한 슬라이드의 핵심 문장입니다. |
| 부제목 | 16-20pt | 중간 | 제목을 짧게 보완합니다. |
| 본문 | 12-15pt | 보통 | 3-5줄 안에서 정리합니다. |
| 캡션 | 9-11pt | 보통 | 출처, 보조 설명에 사용합니다. |
| 큰 숫자 | 34-48pt | 굵게 | 시간 절감, 비용 절감 등 효과를 보여줍니다. |

## 7. 문장 작성 규칙

- 제목은 한 줄로 끝내는 것을 우선합니다.
- 본문은 문단보다 짧은 문장과 목록을 사용합니다.
- 기술 용어는 필요한 경우에만 쓰고, 바로 쉬운 설명을 붙입니다.
- 한 슬라이드에는 하나의 핵심 메시지만 둡니다.
- "AI가 바꿉니다"보다 "반복 업무 시간을 줄입니다"처럼 결과 중심으로 씁니다.

## 8. 슬라이드 구성 원칙

- 표지는 크림 배경에 큰 제목과 딥 그린 포인트를 사용합니다.
- 문제 제기 슬라이드는 흰색 카드 3개 정도로 나누어 보여줍니다.
- 해결책 슬라이드는 딥 그린 배경에 흰색 글자로 강하게 보여줍니다.
- 프로세스는 3단계 또는 5단계 흐름도로 정리합니다.
- 기대 효과는 숫자, 아이콘, 짧은 문장으로 보여줍니다.
- 마지막 슬라이드는 딥 그린 배경에 다음 논의 사항을 간단히 정리합니다.

## 9. 카드와 박스 스타일

- 카드 배경은 흰색을 기본으로 합니다.
- 모서리는 살짝 둥글게 처리합니다. 권장값은 `8-12px`입니다.
- 그림자는 아주 약하게 사용합니다.
- 카드 안에는 제목, 짧은 설명, 아이콘 또는 숫자 하나를 넣습니다.
- 카드가 너무 많으면 산만하므로 한 화면에 3-4개를 넘기지 않습니다.

## 10. 버튼과 강조 요소

PPT 안의 버튼은 실제 클릭 기능보다 "다음 행동"을 보여주는 표시로 사용합니다.

- 기본 버튼: 밝은 그린 배경, 흰색 글자
- 보조 버튼: 투명 배경, 그린 테두리, 그린 글자
- 어두운 배경 위 버튼: 흰색 배경, 그린 글자
- 버튼 모양은 알약처럼 둥글게 처리합니다.
- 버튼 문구 예시: `진단 시작`, `자동화 후보 선정`, `로드맵 확인`

## 11. 아이콘과 이미지 방향

- 아이콘은 얇고 단순한 선형 스타일을 사용합니다.
- 아이콘 색상은 메인 그린 또는 보조 회색으로 통일합니다.
- 이미지가 필요하다면 실제 업무 장면, 회의, 문서, 대시보드처럼 제안 내용과 연결되는 이미지를 사용합니다.
- 막연한 로봇 이미지나 과장된 미래 도시 이미지는 피합니다.
- 특정 회사 로고, 특정 매장, 특정 제품이 떠오르는 이미지는 사용하지 않습니다.

## 12. 추천 슬라이드 패턴

### 표지

- 크림 배경
- 왼쪽에는 큰 제목
- 오른쪽에는 간단한 업무 자동화 흐름도 또는 추상적인 선형 그래픽
- 하단에는 회사명, 날짜, 작성자

### 문제 정의

- 제목: `반복 업무가 성장 속도를 늦추고 있습니다`
- 흰색 카드 3개
- 카드 예시: `문서 작성`, `보고 취합`, `고객 응대`

### 해결 방향

- 딥 그린 배경
- 큰 문장 하나
- 아래에 3단계 흐름: `진단 → 자동화 설계 → 실행 로드맵`

### 기대 효과

- 큰 숫자 3개
- 예시: `업무 시간 절감`, `응답 속도 개선`, `보고 품질 표준화`
- 골드 포인트는 가장 중요한 숫자 하나에만 사용

### 로드맵

- 가로형 단계표
- 단계 예시: `1주차 진단`, `2주차 후보 선정`, `3주차 시나리오 설계`, `4주차 실행 계획`
- 현재 단계나 우선 단계는 밝은 그린으로 표시

## 13. 표와 도식 규칙

- 표는 줄 수를 줄이고 핵심 비교만 남깁니다.
- 표 머리글은 딥 그린 배경에 흰색 글자를 사용합니다.
- 일반 셀은 흰색 배경, 얇은 회색 선을 사용합니다.
- 흐름도는 화살표를 많이 쓰기보다 단계 번호를 크게 보여줍니다.
- 복잡한 구조는 한 번에 설명하지 말고 여러 슬라이드로 나눕니다.

## 14. 여백과 정렬

- 슬라이드 가장자리에는 충분한 여백을 둡니다.
- 제목, 본문, 카드의 왼쪽 기준선을 맞춥니다.
- 내용이 많아지면 글자를 줄이지 말고 슬라이드를 나눕니다.
- 카드 사이 간격은 일정하게 유지합니다.
- 중앙 정렬은 표지나 강한 메시지 슬라이드에만 제한적으로 사용합니다.

## 15. 피해야 할 것

- 특정 브랜드의 로고, 제품명, 매장 사진, 멤버십 화면을 예시로 넣는 것
- 공식 브랜드 디자인 시스템처럼 보이는 표현
- 초록색만 계속 반복해 단조롭게 보이는 구성
- 너무 많은 그림자, 그라데이션, 장식
- 작은 글씨가 빽빽한 보고서형 슬라이드
- AI를 과장되게 표현하는 이미지

## 16. 제작자가 기억할 문장

이 제안서의 디자인은 "따뜻하고 신뢰감 있는 카페형 그린 무드"를 바탕으로 합니다. 하지만 특정 브랜드를 따라 만든 자료처럼 보이면 안 됩니다. 색감과 편안한 분위기만 참고하고, 내용은 AI 자동화 컨설팅 제안에 맞게 전문적이고 쉬운 표현으로 정리합니다.

## 17. 확인 필요

- 고객사 로고를 사용할 수 있는지
- 고객사가 선호하는 색상이나 금지 색상이 있는지
- 실제 업무 화면이나 자료를 넣어도 되는지
- 발표 시간이 몇 분인지
- 제안서가 발표용인지, 이메일 전달용인지
