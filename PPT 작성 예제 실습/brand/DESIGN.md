# 제안서 디자인 초안

이 문서는 AI 자동화 컨설팅 제안서 PPT의 디자인 방향을 정리한 초안입니다. 특정 브랜드의 공식 디자인 시스템이 아니라, 이번 제안서를 일관되게 만들기 위한 내부 기준입니다.

## 전체 분위기

- 신뢰감 있고 차분한 느낌을 우선합니다.
- 너무 화려한 장식보다 내용이 잘 읽히는 구성을 사용합니다.
- AI 기술을 어렵게 보이지 않게, 업무 개선과 실행 가능성을 중심으로 표현합니다.

## 추천 색상

- 기본 글자색: 짙은 회색 `#1F2933`
- 보조 글자색: 중간 회색 `#52606D`
- 배경색: 거의 흰색 `#F8FAFC`
- 강조색: 선명한 파랑 `#2563EB`
- 보조 강조색: 청록색 `#0F766E`
- 경고나 주의 표시: 부드러운 주황 `#F59E0B`

## 글꼴 방향

- 제목은 굵고 짧게 씁니다.
- 본문은 한 슬라이드에 너무 많이 넣지 않습니다.
- 한국어 가독성이 좋은 기본 글꼴을 사용합니다.
- 예시 글꼴: 맑은 고딕, Pretendard, Noto Sans KR

## 슬라이드 구성 원칙

- 한 슬라이드에는 하나의 핵심 메시지만 담습니다.
- 숫자, 단계, 전후 비교는 크게 보여줍니다.
- 표는 꼭 필요한 경우에만 사용하고, 행과 열을 줄입니다.
- 복잡한 설명은 도식, 흐름도, 체크리스트로 바꿉니다.

## 이미지와 아이콘 방향

- 실제 업무 장면, 대시보드, 자동화 흐름을 떠올릴 수 있는 이미지를 사용합니다.
- 막연한 AI 이미지보다 고객의 업무 문제와 연결되는 시각 자료를 우선합니다.
- 아이콘은 단순하고 같은 스타일로 맞춥니다.

## 피해야 할 것

- 모든 슬라이드를 같은 색 하나로만 채우는 구성
- 작은 글씨가 빽빽한 보고서형 슬라이드
- 출처가 불분명한 로고나 이미지 사용
- 특정 회사의 공식 디자인이라고 오해될 수 있는 표현

## 확인 필요

- 고객사 로고 사용 가능 여부
- 제안서에 들어갈 실제 업무 화면이나 데이터 사용 가능 여부
- 발표자의 선호 색상 또는 기존 회사 소개서 스타일
