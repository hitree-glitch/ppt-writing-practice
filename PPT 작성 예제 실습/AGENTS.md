# AI 자동화 컨설팅 제안서 작업 안내

이 폴더는 AI 자동화 컨설팅 제안서 PPT를 만들기 위한 작업 공간입니다. 목표는 비개발자도 이해할 수 있는 AI 자동화 컨설팅 제안서 PPT를 만드는 것입니다.

## 목표

- 내부 개발팀이 없는 10~50명 규모의 SMB 대표가 바로 이해할 수 있는 제안서를 만듭니다.
- AI 자동화 컨설팅의 필요성, 진행 방식, 기대 효과를 쉬운 말로 설명합니다.
- 단순히 AI 도구를 소개하는 자료가 아니라, 반복 업무가 굴러가는 구조를 제안하는 PPT를 만듭니다.

## 말투

- 쉬운 우리말로 설명합니다.
- 어려운 기술 용어는 첫 등장 때 한 문장으로 풀어 설명합니다.
- 대표가 바로 이해할 수 있게 과장보다 구체적인 효과를 우선합니다.
- "AI가 모든 것을 바꿉니다"보다 "반복 보고서 작성 시간을 줄입니다"처럼 실제 업무 효과를 말합니다.

## 폴더 구성

- `brand/`: 제안서의 분위기, 색상, 글꼴, 화면 구성 기준을 정리합니다.
- `context/`: 고객 상황, 제안 목적, 발표 흐름 같은 내용을 정리합니다.
- `assets/`: 나중에 PPT에 넣을 이미지, 아이콘, 로고, 참고 자료를 보관합니다. `$imagegen`으로 만든 이미지는 가능하면 `assets/imagegen/`에 저장합니다.
- `output/`: 최종 PPT, PDF, 검수 이미지, 결과물을 보관합니다.

## 기본 작업 원칙

- 초보자가 읽어도 이해할 수 있는 쉬운 말로 작성합니다.
- 특정 브랜드의 공식 디자인 시스템이라고 표현하지 않습니다.
- 확정되지 않은 내용은 `확인 필요`라고 표시합니다.
- 자료 출처가 있는 경우 파일명이나 문서 안에 간단히 남깁니다.
- 사용자가 요청하기 전에는 PPT 파일을 만들지 않습니다.

## PPT 제작 규칙

- PPT를 만들 때는 Presentations 플러그인을 우선 활용합니다.
- 텍스트, 차트, 기본 도형은 가능하면 PowerPoint에서 편집 가능한 객체로 유지합니다.
- 중요한 글자는 이미지 안에 넣지 말고 PPT 텍스트로 배치합니다.
- `brand/DESIGN.md`의 색상, 배경, 버튼, 여백 규칙을 우선 적용합니다.
- `context/business-context.md`의 고객 문제와 핵심 메시지를 내용 기준으로 삼습니다.
- `context/deck-brief.md`의 발표 목적과 흐름을 슬라이드 구성 기준으로 삼습니다.
- 완료 전 `output/review-montage.png`와 검수 요약을 만듭니다.

## 이미지 제작 및 삽입 규칙

- 전체 덱에는 최소 3개 정도의 이미지를 활용하는 것을 권장합니다.
- 새 이미지가 필요하면 `$imagegen`을 활용해 만들 수 있습니다.
- `$imagegen`으로 만든 이미지는 프로젝트에서 다시 사용할 수 있도록 `assets/imagegen/` 폴더에 저장합니다.
- 이미지는 표지, 문제 상황, 자동화 적용 장면, 기대 효과처럼 분위기와 맥락을 보여주는 영역에 우선 사용합니다.
- 중요한 문장, 숫자, 차트, 업무 흐름도는 이미지 안에 넣지 말고 PPT 텍스트와 편집 가능한 도형으로 배치합니다.
- 생성 이미지에는 특정 브랜드 로고, 실제 회사 로고, 읽어야 하는 글자, 제품명, 계정 화면, 결제 화면을 넣지 않습니다.
- 이미지가 필요한 경우에도 표, 도식, 아이콘처럼 수정이 자주 필요한 요소는 PowerPoint 객체로 만드는 것을 우선합니다.
- 이미지 생성 후에는 슬라이드 안에서 잘리지 않는지, 글자와 겹치지 않는지, 분위기가 `brand/DESIGN.md`와 맞는지 확인합니다.

## 안전 규칙

- 외부 웹 접속이나 데스크톱 앱 조작이 필요하면 먼저 왜 필요한지 설명하고 승인을 요청합니다.
- 비밀키, 결제, 계정 설정 화면은 자동 조작하지 않습니다.
- 고객사 내부 자료나 민감한 정보는 사용 가능 여부를 먼저 확인합니다.
- 출처가 불분명한 로고, 이미지, 캡처 화면은 제안서에 넣지 않습니다.

## 다음 작업자가 확인할 것

- 제안 대상 고객의 업종과 회사 상황
- 고객이 겪는 가장 큰 반복 업무 문제
- 제안서가 설득해야 하는 최종 의사결정자
- 발표용인지, 이메일 전달용인지, 둘 다 필요한지
- 사용할 수 있는 로고, 이미지, 실제 사례 자료
- 최종 PPT 분량과 발표 시간
