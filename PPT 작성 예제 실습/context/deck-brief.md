# AI 자동화 컨설팅 제안서 PPT 브리프

이 문서는 나중에 만들 PPT의 목적, 독자, 흐름, 슬라이드별 내용을 정리한 초안입니다. 아직 PPT 파일은 만들지 않습니다.

## PPT 목적

내부 개발팀이 없는 10~50명 규모의 SMB 대표에게 AI 자동화 컨설팅이 왜 필요한지 설명하고, 4주 안에 어떤 업무부터 자동화 구조를 만들 수 있는지 보여주는 것이 목적입니다.

## 예상 독자

- 내부 개발팀이 없는 SMB 대표
- 운영, 영업, 고객 응대까지 함께 보는 공동대표
- 실무 자동화가 필요하지만 어디서부터 시작할지 모르는 의사결정자

## 핵심 메시지

AI 도구 하나를 더 사는 게 아니라, 반복 업무가 굴러가는 구조를 만듭니다.

## 쉬운 용어 설명 기준

- 클로드코드와 코덱스: 사람이 요청한 일을 바탕으로 문서, 코드, 파일 정리 작업을 도와주는 AI 작업 도우미입니다.
- n8n: 여러 업무 도구를 연결해 "문의가 들어오면 알림을 보내고, 답변 초안을 만들고, 기록을 남기는" 흐름을 만드는 자동화 도구입니다.
- 자동화: 사람이 매번 손으로 하던 반복 절차를 정해진 순서대로 자동으로 처리하게 만드는 것입니다.
- 검수: AI나 자동화가 만든 결과를 사람이 마지막으로 확인하는 단계입니다.

## 이미지 활용 방향

전체 덱에는 최소 3개 정도의 이미지를 활용하는 것을 권장합니다. 이미지는 설명을 대신하는 용도가 아니라, 대표가 상황을 빠르게 이해하도록 돕는 분위기와 맥락용 자료로 사용합니다.

- 이미지가 필요하면 `$imagegen`을 활용해 생성할 수 있습니다.
- 생성 이미지는 `assets/imagegen/`에 저장한 뒤 PPT에 삽입합니다.
- 중요한 제목, 숫자, 표, 차트, 업무 흐름도는 이미지 안에 넣지 않고 PPT 텍스트와 도형으로 만듭니다.
- 이미지에는 특정 브랜드 로고, 실제 회사명, 계정 화면, 결제 화면, 읽어야 하는 작은 글자를 넣지 않습니다.
- 추천 이미지 삽입 위치: 1번 표지, 3번 문제 상황, 6번 문서 업무 자동화, 8번 고객 문의 자동화, 13번 기대 효과 중 최소 3개 이상

## 추천 발표 흐름

1. 대표에게 반복 업무가 몰리는 현실을 보여줍니다.
2. AI 도구만 사는 것으로는 해결되지 않는 이유를 설명합니다.
3. 클로드코드, 코덱스, n8n을 어떻게 업무 구조에 넣을 수 있는지 보여줍니다.
4. 고객 문의, 보고서, 자료 정리, 제안서 작성 예시를 구체적으로 보여줍니다.
5. 4주 컨설팅으로 어떤 산출물이 나오는지 설명합니다.
6. 바로 다음에 확인해야 할 업무 후보를 정리합니다.

## 슬라이드별 구성 초안

### 1. 표지

- 제목: `AI 자동화 진단 및 업무 시스템 구축 제안`
- 부제: `대표에게 몰린 반복 업무를 줄이고, 업무가 굴러가는 구조를 만듭니다`
- 포함 내용: 고객사명, 제안일, 작성자
- 시각화: 크림 배경, 딥 그린 제목, 간단한 자동화 흐름 선 그래픽
- 이미지 후보: `$imagegen`으로 따뜻한 사무실, 노트북, 문서, 자동화 흐름을 암시하는 추상적 선 요소가 있는 대표 이미지를 생성합니다. 이미지 안에는 글자와 로고를 넣지 않습니다.

### 2. 제안 대상과 한 줄 결론

- 핵심 문장: `내부 개발팀이 없어도 AI 자동화는 작게 시작할 수 있습니다`
- 포함 내용:
  - 대상: 10~50명 규모의 SMB
  - 상황: 대표와 핵심 실무자에게 반복 업무가 몰림
  - 결론: 도구 구매보다 업무 흐름 설계가 먼저 필요함
- 시각화: `대표/실무자 → 반복 업무 → 자동화 구조` 흐름도

### 3. 지금 대표에게 몰리는 업무

- 핵심 문장: `매출을 만들어야 할 시간이 반복 업무에 쓰이고 있습니다`
- 포함 내용:
  - 반복 보고서 작성
  - 고객 문의 답변
  - 자료 정리
  - 제안서 초안 작성
  - 메일, 파일, 메신저 내용 취합
- 시각화: 흰색 카드 5개 또는 업무 더미 형태
- 이미지 후보: `$imagegen`으로 책상 위 문서, 노트북, 알림이 많은 업무 과부하 장면을 생성합니다. 실제 앱 화면이나 읽을 수 있는 글자는 넣지 않습니다.

### 4. AI 도구만 추가하면 생기는 문제

- 핵심 문장: `AI를 써도 업무 순서가 없으면 다시 사람이 정리해야 합니다`
- 포함 내용:
  - 누가 어떤 자료를 넣을지 정해져 있지 않음
  - AI가 만든 결과를 누가 확인할지 불분명함
  - 고객 문의와 보고 기록이 따로 흩어짐
  - 좋은 답변을 만들어도 다음 업무로 이어지지 않음
- 시각화: `도구만 추가`와 `업무 구조 설계` 비교표

### 5. 제안하는 자동화 구조

- 핵심 문장: `AI 작업 도우미와 자동화 흐름을 함께 설계합니다`
- 포함 내용:
  - 클로드코드/코덱스: 문서, 코드, 파일 정리, 제안서 초안 작성 보조
  - n8n: 반복 알림, 데이터 이동, 고객 문의 분류, 기록 자동화
  - 사람 검수: 중요한 답변과 문서는 사람이 최종 확인
- 시각화: `입력 → AI 작업 → n8n 연결 → 사람 검수 → 결과 기록`

### 6. 활용 예시 1: 클로드코드/코덱스로 문서 업무 줄이기

- 핵심 문장: `대표가 매번 직접 쓰던 문서 초안을 AI가 먼저 정리합니다`
- 포함 내용:
  - 회의 메모를 보고 제안서 목차 초안 만들기
  - 기존 자료를 읽고 보고서 초안 정리하기
  - 고객별 제안서 문구를 바꾸는 작업 보조
  - 폴더 안 자료를 기준에 맞게 정리하기
  - 반복적으로 쓰는 문서 양식 만들기
- 시각화: `자료 폴더 → AI 작업 도우미 → 보고서/제안서 초안`
- 이미지 후보: `$imagegen`으로 흩어진 자료가 정리된 문서 초안으로 바뀌는 업무 장면을 생성합니다. 문서 제목과 본문은 PPT 텍스트로 따로 배치합니다.

### 7. 활용 예시 2: 클로드코드/코덱스로 내부 업무 도구 만들기

- 핵심 문장: `복잡한 개발 프로젝트가 아니어도 작은 업무 도구부터 만들 수 있습니다`
- 포함 내용:
  - 고객 문의를 붙여 넣으면 답변 초안을 만드는 간단한 양식
  - 제안서에 들어갈 고객 정보 정리표
  - 반복 보고서 생성을 위한 템플릿
  - 엑셀/CSV 자료를 보기 쉽게 정리하는 간단한 스크립트
  - 업무 체크리스트를 자동으로 만드는 문서 양식
- 시각화: `반복 입력 → 작은 도구 → 빠른 결과`

### 8. 활용 예시 3: n8n으로 고객 문의 흐름 자동화

- 핵심 문장: `문의가 들어온 뒤의 반복 절차를 자동으로 이어줍니다`
- 포함 내용:
  - 문의 접수
  - 문의 유형 분류
  - 담당자에게 알림
  - 답변 초안 생성
  - 고객 관리 시트나 CRM에 기록
  - 미응답 문의 재알림
- 시각화: 가로형 6단계 자동화 흐름도
- 이미지 후보: `$imagegen`으로 여러 문의 채널이 하나의 자동화 허브로 모이는 추상 이미지를 생성합니다. 단계명과 화살표는 PowerPoint 도형으로 만듭니다.

### 9. 활용 예시 4: n8n으로 보고서 작성 준비 자동화

- 핵심 문장: `보고서를 쓰기 전에 필요한 자료 수집과 정리를 자동화합니다`
- 포함 내용:
  - 정해진 시간에 데이터 가져오기
  - 구글 시트, 엑셀, 이메일 자료 모으기
  - 주요 숫자 요약하기
  - 보고서 초안 작성 요청 보내기
  - 담당자에게 검토 알림 보내기
- 시각화: `데이터 수집 → 요약 → 초안 → 검토 알림`

### 10. 자동화 후보 업무 우선순위

- 핵심 문장: `처음에는 효과가 크고 위험이 낮은 업무부터 시작합니다`
- 포함 내용:
  - 1순위: 반복 보고서 작성 준비
  - 2순위: 고객 문의 분류와 답변 초안
  - 3순위: 자료 정리와 제안서 초안
  - 4순위: 내부 알림과 업무 기록
- 시각화: 효과와 난이도 2축 매트릭스

### 11. 4주 컨설팅 진행 방식

- 핵심 문장: `4주 동안 진단에서 실행 준비까지 정리합니다`
- 포함 내용:
  - 1주차: 반복 업무 진단
  - 2주차: 자동화 후보 선정
  - 3주차: AI/n8n 업무 흐름 설계
  - 4주차: 실행 로드맵과 운영 기준 정리
- 시각화: 4단계 로드맵

### 12. 최종 산출물

- 핵심 문장: `끝나고 나면 바로 실행할 수 있는 기준이 남습니다`
- 포함 내용:
  - 반복 업무 목록
  - 자동화 우선순위표
  - 클로드코드/코덱스 활용 시나리오
  - n8n 자동화 흐름 설계안
  - 검수와 운영 기준
  - 다음 구축 단계 로드맵
- 시각화: 산출물 체크리스트

### 13. 기대 효과

- 핵심 문장: `대표의 시간을 반복 업무에서 중요한 의사결정으로 옮깁니다`
- 포함 내용:
  - 보고서 작성 준비 시간 감소
  - 고객 문의 응답 속도 개선
  - 제안서 초안 작성 부담 완화
  - 업무 처리 기준 표준화
  - 내부 개발팀 없이도 시작 가능한 자동화 계획 확보
- 시각화: 큰 숫자 3개와 짧은 설명
- 이미지 후보: `$imagegen`으로 대표가 반복 문서 작업에서 벗어나 회의나 전략 논의에 집중하는 장면을 생성합니다. 핵심 숫자는 이미지가 아니라 PPT 텍스트로 배치합니다.

### 14. 안전한 운영 방식

- 핵심 문장: `자동화는 사람이 확인하는 구조와 함께 설계해야 안전합니다`
- 포함 내용:
  - 고객 답변은 발송 전 사람이 확인
  - 중요한 문서는 최종 검수 후 사용
  - 민감한 정보는 자동화 대상에서 제외하거나 권한을 제한
  - 오류가 생겼을 때 사람이 멈출 수 있는 절차 마련
- 시각화: `AI 처리 → 사람 검수 → 발송/기록` 3단계

### 15. 다음 단계

- 포함 내용:
  - 현재 가장 시간이 많이 드는 업무 확인
  - 문의 채널과 보고서 양식 확인
  - 사용 중인 도구 목록 확인
  - 4주 진단 일정 확정
- 시각화: 체크리스트 또는 다음 미팅 아젠다

## 자동화 사례 상세 메모

### 클로드코드/코덱스 활용 업무

- 문서 초안 작성: 회의 메모, 기존 제안서, 고객 정보로 새 제안서 초안을 만듭니다.
- 자료 정리: 폴더 안 문서와 표를 읽고 필요한 항목을 기준에 맞게 정리합니다.
- 반복 양식 생성: 보고서, 고객 응대 답변, 내부 체크리스트 양식을 만듭니다.
- 작은 업무 도구 제작: 입력 폼, 간단한 정리 스크립트, 템플릿 생성 도구를 만듭니다.
- 제안서 제작 보조: 슬라이드 목차, 장표 문구, 표와 도식 초안을 정리합니다.

### n8n 활용 업무

- 고객 문의 자동 분류: 문의가 들어오면 유형을 나누고 담당자에게 알립니다.
- 답변 초안 요청: 문의 내용을 AI에 보내 답변 초안을 만들고 검수자에게 전달합니다.
- 보고 자료 수집: 정해진 시간에 이메일, 시트, 파일 자료를 모읍니다.
- 기록 자동화: 처리 결과를 고객 관리 시트나 업무 관리 도구에 남깁니다.
- 재알림: 일정 시간 동안 처리되지 않은 문의나 업무를 다시 알려줍니다.

## `$imagegen` 프롬프트 초안

아래 프롬프트는 나중에 이미지가 필요할 때 시작점으로 사용할 수 있습니다. 실제 생성 전에는 고객 업종과 발표 톤에 맞게 조금 다듬습니다.

### 표지 이미지

```text
Use case: productivity-visual
Asset type: PowerPoint cover image
Primary request: 따뜻한 크림색 사무실에서 작은 회사 대표가 노트북과 문서를 보며 업무 자동화 흐름을 준비하는 장면
Style/medium: 세련된 비즈니스 일러스트 또는 자연스러운 에디토리얼 스타일
Composition/framing: 와이드 화면, 오른쪽에 이미지 중심, 왼쪽에는 PPT 제목을 올릴 여백
Lighting/mood: 따뜻하고 신뢰감 있는 분위기
Color palette: 크림 배경, 딥 그린 포인트, 밝은 그린 보조 포인트
Constraints: 로고 없음, 읽을 수 있는 글자 없음, 특정 브랜드 화면 없음, 워터마크 없음
```

### 문제 상황 이미지

```text
Use case: productivity-visual
Asset type: slide supporting image
Primary request: 문서, 이메일 알림, 고객 문의, 보고서 자료가 한 사람에게 몰려 있는 작은 회사 업무 과부하 장면
Style/medium: 깨끗한 비즈니스 일러스트
Composition/framing: 책상과 노트북 중심, 주변에 문서와 알림을 상징하는 추상 요소 배치
Lighting/mood: 부담은 느껴지지만 과장되지 않은 현실적인 분위기
Color palette: 크림, 흰색, 딥 그린, 부드러운 주황 포인트
Constraints: 실제 앱 UI 없음, 읽을 수 있는 글자 없음, 로고 없음, 워터마크 없음
```

### 고객 문의 자동화 이미지

```text
Use case: productivity-visual
Asset type: slide supporting image
Primary request: 여러 고객 문의 채널이 하나의 자동화 흐름으로 모이고, 담당자 확인 후 기록되는 모습을 추상적으로 표현한 이미지
Style/medium: 현대적인 업무 자동화 일러스트
Composition/framing: 왼쪽에는 여러 입력 채널을 상징하는 말풍선과 문서, 중앙에는 자동화 허브, 오른쪽에는 검수와 기록을 상징하는 사람과 체크 표시
Lighting/mood: 차분하고 정돈된 분위기
Color palette: 크림 배경, 딥 그린, 밝은 그린, 소프트 그린
Constraints: 단계명 텍스트 없음, 브랜드 로고 없음, 실제 계정 화면 없음, 워터마크 없음
```

## 자료 준비 목록

- 고객사 기본 정보
- 고객이 자주 받는 문의 예시
- 기존 보고서 또는 주간 업무 정리 샘플
- 기존 제안서 또는 고객 설명 자료
- 사용 중인 도구 목록: 이메일, 메신저, 문서 도구, 시트, CRM 등
- 자동화하면 안 되는 민감 정보 기준
- 로고, 색상, 사진 등 사용 가능한 시각 자료

## 작성 톤

- 어려운 기술 용어보다 쉬운 업무 언어를 사용합니다.
- 문제를 과장하지 않고, 실행 가능한 해결책을 보여줍니다.
- AI가 사람을 대체한다는 느낌보다, 사람이 중요한 일에 집중하도록 돕는다는 메시지를 사용합니다.
- 클로드코드, 코덱스, n8n은 도구 이름보다 "어떤 업무 시간이 줄어드는지"와 함께 설명합니다.

## 확인 필요

- 발표 시간
- 발표 방식: 대면 발표, 온라인 발표, 이메일 전달
- 최종 PPT 분량
- 고객이 가장 관심 있어 하는 성공 지표
- 실제로 사용할 도구가 클로드코드, 코덱스, n8n 중 무엇인지
- 고객사가 이미 쓰고 있는 협업 도구와 고객 관리 도구
