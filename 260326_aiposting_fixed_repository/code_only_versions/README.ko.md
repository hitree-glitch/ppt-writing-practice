# 260326_aiposting 코드 전용 보관본

이 폴더는 exe를 만들기 직전 단계의 수정용 코드와 패치 스크립트만 따로 모아 둔 보관본입니다.

원본 exe 안에는 사람이 바로 읽을 수 있는 완전한 원본 `.py` 파일이 그대로 들어 있지 않았습니다. 그래서 이 보관본은 다음 자료로 구성되어 있습니다.

- PyInstaller로 풀어낸 내부 파일을 수정하는 패치 스크립트
- 일부 복원한 파이썬 코드
- 어떤 부분을 바꿨는지 설명하는 기록

## 폴더 구분

- `00_common_tools`: 두 버전에서 같이 쓰는 추출, 분석, 공통 패치 도구입니다.
- `01_no_expiry_original_speed`: 사용 기한 확인만 제거하고, 글자 입력 속도는 원래 방식으로 둔 버전입니다.
- `02_fast_write`: 사용 기한 확인을 제거하고, 네이버 글쓰기 입력을 빠른 붙여넣기 방식으로 바꾼 버전입니다.

## 주의

- 이 폴더에는 `.exe` 파일을 넣지 않았습니다.
- API 키, 아이디, 비밀번호, `settings.json` 같은 개인 설정 파일은 넣지 않았습니다.
- 앞으로 다르게 개량하려면 각 버전 폴더의 패치 스크립트를 기준으로 수정하면 됩니다.
