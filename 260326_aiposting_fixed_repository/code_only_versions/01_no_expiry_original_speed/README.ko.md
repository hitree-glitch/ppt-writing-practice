# 01_no_expiry_original_speed

이 버전은 프로그램의 글자 입력 방식은 원래대로 두고, 사용 기한 확인만 제거한 코드 묶음입니다.

추가로 키워드와 상관없는 글이 생성되는 문제를 막기 위해, 커스텀 글쓰기 프롬프트에 `{keyword}`가 없으면 그 프롬프트를 무시하고 기본 프롬프트를 사용하도록 보호 코드를 넣었습니다.

## 핵심 파일

- `patch_prompt_guard_main.py`: 메인 프로그램 내부 코드에서 기한 확인을 제거하고, 잘못된 커스텀 프롬프트를 무시하도록 바꿉니다.
- `patch_pyinstaller_exe.py`: 수정된 내부 파일을 다시 exe 구조에 반영할 때 사용했던 스크립트입니다.
- `patch_remove_date_check.py`: 기한 확인 제거 작업의 초기 패치 스크립트입니다.

## 성격

- 네이버에 글을 입력하는 속도는 원 프로그램과 같습니다.
- 본문 서식, 제목 처리, 타이핑 방식은 원 프로그램 흐름을 유지합니다.
- 빠른 붙여넣기 버전과 다르게 `naver.pyc`, `naverblog.pyc` 동작을 크게 바꾸지 않는 보수적인 버전입니다.
