# 02_fast_write

이 버전은 사용 기한 확인을 제거하고, 네이버 글쓰기 입력을 빠른 방식으로 바꾼 코드 묶음입니다.

원래 프로그램은 글자가 타이핑되는 것처럼 천천히 입력되도록 되어 있었습니다. 이 버전은 가능한 경우 본문을 한 번에 넣고, 문단 간 공백과 제목 구분이 더 잘 보이도록 만든 실험용 개선판입니다.

## 핵심 파일

- `patch_fixed_exe.py`: 빠른 글쓰기 버전 exe를 만들 때 사용했던 전체 패치 스크립트입니다.
- `patch_fast_paste.py`: 네이버 글쓰기 입력 속도를 빠르게 바꾸는 핵심 패치입니다.
- `naverblog_fast_readable.py`: 빠른 붙여넣기와 가독성 개선 로직을 사람이 보기 쉽게 정리한 코드입니다.
- `naver_runtime_patch.py`: 네이버 검색/상위글 관련 런타임 패치 코드입니다.
- `naverblog_runtime_patch.py`: 네이버 블로그 글쓰기 관련 런타임 패치 코드입니다.
- `patch_prompt_guard_main.py`: 기한 확인 제거와 잘못된 커스텀 프롬프트 무시 처리를 담당합니다.

## 성격

- 글자 입력 대기 시간을 줄이는 데 초점을 둔 버전입니다.
- 소제목은 더 크고 굵게 보이도록 처리하는 방향입니다.
- 문장과 문단 사이 공백을 더 넉넉하게 두는 방향입니다.
- 네이버 에디터 구조가 바뀌면 이 버전이 원본 속도 버전보다 영향을 더 받을 수 있습니다.
