# 참고 자료 기반 블로그 초안 생성 프로그램

네이버 블로그용 새 글을 만들기 전에 참고 자료를 수집, 분석하고 초안을 생성하는 Python GUI 프로그램입니다. 자동 발행, 네이버 로그인, 자동 포스팅 기능은 포함하지 않습니다.

## 설치 방법

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 실행 방법

```bash
python main.py
```

## Gemini API 키 입력 방법

1. Google AI Studio에서 Gemini API 키를 발급받습니다.
2. 프로그램 화면의 `Gemini API 키` 입력칸에 붙여 넣습니다.
3. API 키가 없으면 기본 초안 생성 모드로 실행되지만, 품질은 Gemini 사용 시보다 낮습니다.

## 참고 URL 기반 작성 방법

1. 작성 방식을 `① 네이버 블로그 URL 참고`로 선택합니다.
2. 참고 URL 입력칸에 네이버 블로그 URL을 한 줄에 하나씩 입력합니다.
3. 원하는 글자 수와 문체를 선택합니다.
4. `글 생성` 버튼을 누릅니다.

프로그램은 네이버 블로그의 iframe 구조를 처리하고, 제목과 본문을 추출한 뒤 핵심 주제, 반복 키워드, 독자 질문, 글 흐름, 부족한 점, 보완 방향을 분석합니다.

## 해외 자료 검색 기반 작성 방법

1. 작성 방식을 `② 주제/키워드로 해외 자료 검색`으로 선택합니다.
2. 주제/키워드 입력칸에 검색어를 입력합니다.
3. `글 생성` 버튼을 누릅니다.

기본 검색은 API 키 없이 DuckDuckGo HTML 검색을 사용합니다. 검색이나 본문 추출에 실패하면 참고 URL 방식으로 직접 URL을 입력해 진행할 수 있습니다.

## txt/docx 저장 방법

초안이 생성된 뒤 `txt 저장` 또는 `docx 저장` 버튼을 누르고 저장 위치를 선택하면 됩니다.

## 추가 GUI 기능

- `크롤링 확인`: 글 생성 전에 실제 추출된 제목, URL, 글자 수, 본문 미리보기를 확인합니다.
- `글쓰기 프롬프트 수정`: Gemini에 전달할 글쓰기 지시문을 수정하고 저장합니다.
- `이미지 프롬프트 수정`: 문단별 영문 이미지 프롬프트 생성 지시문을 수정하고 저장합니다.
- `문단별 영문 이미지 프롬프트`: 생성된 글의 주요 소제목을 바탕으로 이미지 생성용 영어 프롬프트를 표시합니다.
- `무료 이미지 검색`: Pexels, Pixabay, Wikimedia Commons에서 글 내용 관련 이미지 후보를 검색합니다.
- `구독 블로그 자동 감시`: 블로그 ID/URL을 3~5개 입력해 새 글을 RSS로 확인하고 초안을 생성합니다.
- `새 글 1회 확인/처리`: 지금 바로 구독 블로그의 새 글을 확인하고 초안을 생성합니다.
- `4시간 감시 시작`: 앱이 켜져 있는 동안 설정한 시간마다 새 글을 확인합니다.
- `현재 글 네이버 저장 시도`: Playwright 브라우저를 열어 현재 초안을 네이버 글쓰기 화면에 붙여넣고 임시/예약 저장을 시도합니다.
- `API키 발급 링크`: Google AI Studio API 키 발급 페이지를 엽니다.
- `API키 발급 영상`: Gemini API 키 발급 안내 영상을 검색합니다.
- `임시 저장/예약 발행/즉시 발행`: 네이버 저장 자동화에서 사용할 목표 동작을 선택합니다. 실제 성공 여부는 네이버 화면 구조와 로그인 인증 상태에 따라 달라집니다.
- `시작/중지`: 생성 작업을 시작하거나 현재 단계 종료 후 중지하도록 요청합니다.
- `설정 저장`: API 키, 로그인 메모, 프롬프트 설정을 저장합니다. API 키와 로그인 정보는 체크박스를 켠 경우에만 저장됩니다.

## 구독 블로그 자동 감시 사용 방법

프로그램은 `자동 작업대`, `수동 초안`, `설정`, `로그/이력` 4개 탭으로 구성됩니다.

1. `자동 작업대` 탭에서 구독 블로그 ID 또는 URL을 한 줄에 하나씩 입력합니다.
   - 예: `ranto28`
   - 예: `https://blog.naver.com/ranto28`
2. `지금 새 글 확인`을 눌러 새 글 목록을 봅니다.
3. 새 글을 선택하고 `선택 글로 초안 만들기`를 누릅니다.
4. 필요하면 `무료 이미지 찾기`로 관련 이미지를 검색합니다.
5. `네이버 임시저장으로 보내기` 또는 `네이버 예약저장으로 보내기`를 누릅니다.
6. 반복 감시가 필요하면 `4시간 자동 감시 시작`을 누릅니다.

처리 이력은 `automation_state.sqlite3`에 저장되어 같은 글을 반복 처리하지 않습니다. 생성된 초안은 `automation_drafts` 폴더에 저장됩니다.

## 무료 이미지 검색 사용 방법

1. Pexels 또는 Pixabay API 키를 입력하면 검색 후보가 더 풍부해집니다.
2. API 키가 없어도 Wikimedia Commons 검색은 시도됩니다.
3. `현재 글 기준 무료 이미지 검색`을 누르면 후보 URL과 출처 문구가 표시됩니다.
4. `상위 2장 자동 다운로드`를 켜면 `downloaded_images` 폴더에 이미지가 저장되고, 네이버 저장 자동화의 첨부 후보로 사용됩니다.

## 네이버 저장 자동화 준비

Playwright 브라우저가 필요합니다.

```bash
pip install -r requirements.txt
playwright install chromium
```

권장 방식:

1. `수동 로그인 모드(권장)`을 켭니다.
2. `내 블로그 ID`를 입력합니다.
3. 글을 생성한 뒤 `현재 글 네이버 저장 시도`를 누릅니다.
4. 뜨는 브라우저에서 네이버 로그인을 직접 완료합니다.
5. 프로그램이 제목/본문/이미지 붙여넣기를 시도합니다.

네이버 화면 구조, 캡차, 2단계 인증, 에디터 업데이트에 따라 자동 저장이 실패할 수 있습니다. 첫 실행은 반드시 화면을 보면서 확인하세요.

## exe 파일 만드는 방법

```bash
pyinstaller --onefile --windowed main.py
```

완료 후 `dist` 폴더 안의 `main.exe`를 실행하면 됩니다.

## 주의사항

- 생성된 글은 초안이며 발행 전 사람이 반드시 검토해야 합니다.
- 원문을 그대로 복사하면 안 됩니다.
- 해외 자료는 참고용이며 사실관계 확인이 필요합니다.
- 표절 점검은 보조 기능입니다. 최종 법적/윤리적 책임을 대신하지 않습니다.
- 웹사이트 구조가 바뀌거나 접근을 차단하면 본문 추출이 실패할 수 있습니다.
- 구독 블로그 기반 자동화는 원문 재게시가 아니라 참고 자료 기반 재작성 용도로만 사용해야 합니다.
- 네이버 자동화는 서비스 정책과 계정 상태에 영향을 줄 수 있으므로 과도한 반복 발행을 피하세요.
- 무료 이미지도 라이선스와 출처 표기 조건을 확인해야 합니다.
