# 중년 남성 고립·고독사·자살 통합 데이터 연구 세션

이 세션은 본격 분석 전, 논문용 데이터셋으로 확장 가능한 자료원을 확인하고 1차 공식 집계 데이터를 정리한 것입니다.

핵심 판단:

- 이미 작업 폴더에는 `analysis_outputs_middle_male_mortality`가 있으며, 남성 40-64세 개인조사 자료와 KOSIS 성·5세연령별 자살 사망률을 `연도 x 5세연령대`로 결합한 30셀 패널이 존재합니다.
- 새로 확인한 보건복지부 고독사 발표자료는 `연도 x 시도`, `연도 x 성별`, `연도 x 연령대` 공식 집계로 확장 가능합니다.
- KOSIS 사망원인 계열 표 ID는 확인 완료했습니다. 특히 `DT_1B34E01`, `DT_1B34E11`, `DT_1B34E17`, `DT_1B34E18`, `DT_1B34E19`가 자살·사망원인 분석축입니다.

가장 유망한 논문 데이터셋은 두 층으로 구성하는 것입니다.

1. `연도 x 5세연령대` 개인조사-자살률 패널: 우울, 자존감, AUDIT, 소득, 관계/요청회피 문항과 자살률의 생태학적 결합.
2. `연도 x 시도` 공식통계 패널: 고독사, 1인가구 비중, 남성 자살률, 복지 인프라, 사회적 관계망 지표의 지역 취약성 지수.
