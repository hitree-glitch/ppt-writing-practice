## 3. 논문에서 가장 안전한 분석 설계

현재 공개자료만으로 가장 방어 가능한 기본 설계는 다음이다.

```text
정신건강지표_{시도,연도}
= 디지털이용률_{시도,연도}
+ 고령인구비율
+ 독거노인가구비율
+ 기초생활수급자수율 또는 실업률
+ 의료자원 지표
+ 연도 효과
```

현재 자동 추출까지 완료된 결합 분석 가능 기간은 2021-2023년이다. 정신건강과 통제변수는 2016-2024년까지 확보되어 있으므로, 디지털 이용률의 추가 연도만 OCR 또는 원자료 신청으로 보강하면 더 긴 패널 분석으로 확장할 수 있다.

현재 만든 예비 분석에서 가장 눈에 띄는 패턴은 다음이다.

- 단순 상관에서 인터넷 이용률과 우울감 경험률 표준화율은 양의 상관을 보였다(`r = 0.266`, `n = 51`).
- 단순 상관에서 인터넷 이용률과 스트레스 인지율 표준화율은 거의 관계가 없었다(`r = 0.001`, `n = 51`).
- 지역+연도 고정효과 모형에서는 같은 지역 안에서 인터넷 이용률이 올라간 해에 스트레스 인지율도 함께 올라가는 방향의 계수가 나왔다(`b = 0.294`, robust SE `0.103`, 정규근사 `p ≈ 0.004`).
- 우울감 경험률도 같은 방향이지만 더 약했다(`b = 0.127`, robust SE `0.073`, 정규근사 `p ≈ 0.080`).
- 우울감 상담경험률은 디지털 이용률과 안정적인 관계가 보이지 않았다.

따라서 현재 데이터만으로는 “디지털 이용률이 낮아서 정신건강이 나빠진다”보다 “디지털 이용률이 높은 도시화/연결 지역에서 스트레스·우울감 보고가 높게 나타나는가” 또는 “디지털 접근성이 상담 접근성과는 별개로 움직이는가”라는 문제설정이 더 안전하다.

## 4. 해석상 주의

이 데이터는 개인 단위 인과분석이 아니다. 해석은 반드시 집계수준/생태학적 분석으로 제한해야 한다.

가능한 표현:

> 디지털 이용률이 높은/낮은 시도에서 우울감, 스트레스, 상담 접근성 지표가 함께 어떻게 움직이는지 검토한다.

피해야 할 표현:

> AI나 인터넷을 덜 사용한 개인이 우울해졌다.
