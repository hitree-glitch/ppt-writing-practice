# AI/디지털 격차와 정신건강 집계자료 결합 메모

## 1. 수집 완료 자료

공식 공개자료 기준으로 다음 자료를 내려받았다.

- NIA 디지털정보격차 실태조사: 2016-2025년 보고서 10개
- NIA 인터넷이용실태조사: 2016-2017년 보고서, 2018-2025년 통계표/보고서
- NIA 스마트폰/인터넷 과의존 실태조사: 2016-2025년 보고서 10개
- NIA 사이버폭력 실태조사: 2019-2025년 보고서 7개
- 질병관리청 지역사회건강조사: 2008-2019 묶음 통계집, 2020-2025 통계집
- 질병관리청 지역사회 건강결과 및 건강 결정요인 DB v1.7: 2008-2024 연도별 엑셀 시트

전체 파일 목록은 `download_inventory.csv`에 정리했다.

## 2. 바로 분석 가능한 생성 파일

### 정신건강 지표

`chs_mental_health_sido_panel_2016_2024.csv`

- 질병관리청 건강결과 및 건강 결정요인 DB에서 추출
- 단위: 연도 x 시도
- 기간: 2016-2024
- 포함 지표: 우울감 경험률, 스트레스 인지율, 정신상담률, 자살생각률, EQ-5D, 행복감 등

`chs_mental_health_sido_panel_clean_2016_2024.csv`

- 위 파일의 열 이름을 분석용 영문 변수명으로 표준화한 파일
- 논문 분석에는 이 파일을 우선 사용하면 된다.

`chs_mental_health_variable_coverage.csv`

- 정신건강 변수별 결측 여부와 사용 가능한 연도 정리

### 통제변수 후보

`chs_control_candidates_sido_panel_2016_2024.csv`

- 같은 질병관리청 DB에서 통제변수 후보를 넓게 추출
- 고령인구비율, 독거노인가구비율, 1인가구율, 기초생활수급자, 의료자원, 병상, 의사, 재정/소득 관련 변수 등 포함

`chs_control_candidate_coverage.csv`

- 통제변수 후보별 사용 가능 연도와 결측 현황 정리

### 디지털 이용률 지표

`nia_internet_region_indicators_extracted_2022_2023.csv`

- NIA 인터넷이용실태조사 국문 통계표 PDF에서 기계 추출
- 단위: 연도 x 시도
- 기간: 2022-2023
- 포함 지표: 인터넷 이용률, 모바일 인터넷 이용률, 스마트폰 이용률
- 2024-2025 통계표는 이미지형 PDF라 텍스트 추출이 되지 않았다. OCR 또는 수작업 검표가 필요하다.

### 1차 결합 파일

`combined_sido_digital_mental_2022_2023.csv`

- 결합키: `year + sido`
- NIA 지역별 디지털 이용률과 질병관리청 정신건강 지표를 붙인 1차 결합 데이터
- 단위: 2022-2023년 x 17개 시도 = 34행

`combined_sido_digital_mental_correlations_2022_2023.csv`

- 1차 결합 데이터의 단순 피어슨 상관계수
- 표본 수가 작으므로 결과 해석용이 아니라 방향 확인용으로만 사용한다.

## 3. 논문에서 가장 안전한 분석 설계

현재 공개자료만으로 가장 방어 가능한 기본 설계는 다음이다.

```text
정신건강지표_{시도,연도}
= 디지털이용률_{시도,연도}
+ 고령인구비율
+ 독거노인가구비율
+ 기초생활수급자수율
+ 의료자원 지표
+ 연도 효과
```

현재 자동 추출까지 완료된 결합 분석 가능 기간은 2022-2023년이다. 정신건강과 통제변수는 2016-2024년까지 확보되어 있으므로, 디지털 이용률의 추가 연도만 보강하면 패널 분석으로 확장할 수 있다.

## 4. 해석상 주의

이 데이터는 개인 단위 인과분석이 아니다. 해석은 반드시 집계수준/생태학적 분석으로 제한해야 한다.

가능한 표현:

> 디지털 이용률이 낮은 시도에서 우울감, 스트레스, 상담 접근성 지표가 함께 취약하게 나타나는지 검토한다.

피해야 할 표현:

> AI나 인터넷을 덜 사용한 개인이 우울해졌다.
