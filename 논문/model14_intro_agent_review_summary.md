# Model 14 서론 에이전트 검토 요약

검토 대상: `model14_rewritten_introduction.md`
반영본: `model14_rewritten_introduction_reviewed.md`

## 종합 판단

현재 서론의 큰 방향은 통계모형과 일치한다. 핵심 구조는 `사별 고통(GriefTot) -> PTSD 증상(PCLTot) -> 자살위험(SBQTot)`이며, 생성감(LGS_Tot)은 `PTSD 증상 -> 자살위험` 경로를 조절하는 변수로 설정되어 있다. OPQOL/K10은 주모형 변수처럼 남아 있지 않다.

다만 초안은 횡단자료로 검증할 수 있는 주장보다 일부 문장이 강하게 읽힐 수 있으므로, 인과·진단·개입 효과를 단정하는 표현을 완화하는 수정이 필요하다.

## 핵심 수정 포인트

1. 용어는 `사별 고통`으로 유지한다.
   - `사별 트라우마`는 변수명으로 쓰지 않는다.
   - 갑작스러운 사별을 외상 사건이나 PTSD 진단으로 동일시하지 않는다.

2. `PTSD 증상`은 임상 진단이 아니라 PCLTot로 측정한 증상 수준으로 쓴다.
   - 본문에서는 `외상후 스트레스 증상(PTSD 증상)`으로 처음 정의하고 이후 `PTSD 증상`으로 통일한다.

3. 횡단자료의 한계를 서론 말미에 선제적으로 명시한다.
   - 시간적·인과적 매개를 입증하기보다 이론적으로 가정된 간접 관련성과 조건부 관련성을 검증한다고 표현한다.

4. 생성감은 전체 자살위험을 직접 낮추는 요인이 아니라, `PTSD 증상 -> 자살위험` 관련성을 약화시키는 조절변인으로 제한한다.

5. SBQTot의 의미를 명확히 한다.
   - `자살위험`은 자살사고와 자살 관련 행동 가능성을 포괄하는 자기보고 지표로 정의한다.
   - 실제 자살 사망이나 향후 자살시도 발생을 예측한다고 쓰지 않는다.

6. 가설 구조는 PROCESS Model 14와 직접 연결되도록 정리한다.
   - X = 사별 고통
   - M = PTSD 증상
   - Y = 자살위험
   - W = 생성감
   - W는 M -> Y 경로만 조절한다.

## 남은 확인 질문

1. `갑작스러운 사별`의 조작적 기준은 무엇인가?
   - 예: 예상하지 못한 사망, 사고·자살·급성질환, 응답자 주관 판단 등.

2. 표본의 노년층 기준은 무엇인가?
   - 60세 이상인지, 65세 이상인지, 또는 연구 표본의 평균 연령에 따른 표현인지 확인 필요.

3. PCLTot가 19문항으로 분석된 이유를 확인해야 한다.
   - PCL-5는 일반적으로 20문항이므로 누락/제외 문항 여부를 방법에 설명해야 한다.

4. 핵심 경로를 직접 지지하는 문헌 보강이 필요하다.
   - 사별 고통 -> PTSD 증상
   - PTSD 증상 -> 자살위험
   - 생성감의 스트레스/자살위험 완충효과

## 반영된 수정

- 인과적 표현을 `높인다`, `전이된다`, `억제한다`에서 `관련된다`, `약화될 가능성이 있다`, `조절변인으로 기능한다`로 완화했다.
- `사별 고통`과 `PTSD 증상`의 개념 구분을 명시했다.
- `자살위험`을 자기보고 지표로 정의했다.
- 연구목적 문단에 PROCESS Model 14의 X/M/Y/W 역할을 명시했다.
- 횡단자료의 해석 한계를 서론에 선제적으로 넣었다.
- 가설을 5개로 재정리하여 Model 14와 더 직접적으로 맞췄다.
